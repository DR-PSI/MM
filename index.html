01
PM Scheduling
วางแผนและกำหนดตารางงาน Preventive Maintenance ประจำปีในระบบ Maximo ให้ครบถ้วนก่อนเริ่มปีงบประมาณ
# การดำเนินการ รายละเอียด / เส้นทางใน Maximo
1 เข้าสู่โมดูล PM Preventive Maintenance › PM List — Login ด้วย User ที่มีสิทธิ์ PM Planner
2 ค้นหา PM Route Filter ด้วย Site = ฝข และ Active = Yes เพื่อดึง PM Route ทั้งหมดในเขตพื้นที่
3 ตรวจสอบ Frequency ตรวจ Frequency / Estimated Duration ให้ตรงกับ TOR ประจำปี ⚠ ต้องตรวจก่อน Generate
4 Generate Work Orders Actions › Generate WO — เลือก PM ทั้งหมดในเขต แล้วกด Generate ✓ ระบบสร้าง WO อัตโนมัติ
5 ตรวจสอบ WO Status ไปที่ Work Orders › Work Order Tracking — ตรวจว่า Status = WAPPR หรือ APPR
💡 เคล็ดลับ: ตรวจสอบ PM Calendar ทุกต้นปีงบประมาณก่อน Generate WO — หาก Frequency ผิด จะทำให้จำนวนใบงานผิดทั้งปี
02
Station ID
ระบุและผูกสถานีที่ต้องทำ PM ให้ถูกต้องกับ Work Order ในระบบ Maximo ก่อนส่งช่างลงพื้นที่
# การดำเนินการ รายละเอียด / เส้นทางใน Maximo
1 เปิด Work Order เปิด WO ที่ Generate จาก PM ใน Work Order Tracking
2 ตรวจสอบ Location Field Tab Work Order → ช่อง Location ต้องไม่ว่าง ถ้าว่างให้ค้นหาจาก Lookup
3 ค้นหา Station ID คลิก 🔍 ในช่อง Location → พิมพ์ชื่อสถานีหรือรหัส Feeder เพื่อค้นหา
4 ยืนยัน Asset ตรวจ Tab Assets — Asset ต้องถูกผูกกับ Location นั้น ถ้าไม่มีให้เพิ่มก่อน
5 บันทึก Station Code บันทึก Station Code ลงในช่อง Long Description เพิ่มเติม เพื่อให้ช่างอ้างอิงในสนาม
6 แนบเอกสาร Tab Attachments → แนบแผนที่สถานีหรือรูปถ่ายประกอบ (ไฟล์ PDF/JPG)
💡 เคล็ดลับ: Station ID ต้องตรงกับ Feeder/Line ID ในระบบ GIS ของ กฟน. — ตรวจสอบกับ GIS Team ก่อนบันทึก
03
เบิกพัสดุ
เบิกวัสดุและอุปกรณ์ที่ต้องใช้ในงาน PM จาก Storeroom ผ่านระบบ Maximo ให้ถูกต้องและครบถ้วน
# การดำเนินการ รายละเอียด / เส้นทางใน Maximo
1 เปิด Tab Materials เปิด WO → Tab Materials — ตรวจ Planned Materials ที่ระบบกำหนดไว้แล้ว
2 เพิ่มรายการเบิก คลิก New Row → ค้นหา Item Number จาก Item Lookup ℹ ค้นได้จากชื่อหรือรหัสสินค้า
3 ระบุจำนวน กรอก Qty Requested ตามปริมาณจริงที่ต้องใช้งาน
4 เลือก Storeroom เลือก Storeroom ที่ถูกต้อง → ตรวจสอบ Current Balance ว่ามีพอ ⚠ หากไม่พอต้องขอ PR ก่อน
5 Issue Material Actions › Issue Current MRs — ระบบตัดยอด Stock และบันทึก Material Usage
6 พิมพ์ใบเบิก Actions › Print Material Issue Slip — พิมพ์ให้ผู้ควบคุมคลังเซ็นรับ
💡 เคล็ดลับ: ตรวจสอบ Stock Level ก่อนเบิก — หากไม่พอ แจ้ง Warehouse ล่วงหน้าอย่างน้อย 3 วันทำการ เพื่อให้ทันส่งช่างลงพื้นที่
04
โอนพัสดุ
โอนย้ายพัสดุระหว่างใบงาน PM หรือระหว่าง Storeroom เมื่อมีการเปลี่ยนแปลงขอบเขตงาน
# การดำเนินการ รายละเอียด / เส้นทางใน Maximo
1 เปิดหน้า Transfer Inventory › Issue and Transfer — เลือกประเภทธุรกรรม
2 เลือกประเภทการโอน Transfer (โอนระหว่าง Storeroom) หรือ Return (คืนของจาก WO) ขึ้นอยู่กับสถานการณ์
3 ระบุ From/To กรอก From Storeroom และ To Storeroom / To Work Order ให้ถูกต้อง
4 ค้นหา Item ค้นหา Item ที่ต้องการโอนจาก Item Lookup และตรวจสอบ Balance ต้นทาง
5 ยืนยันการโอน ระบุจำนวนและคลิก Save — ระบบจะตัดยอดต้นทางและเพิ่มปลายทางทันที
6 พิมพ์ใบโอน พิมพ์ Transfer Slip เป็นหลักฐานประกอบเอกสาร ⚠ ต้องได้รับอนุมัติก่อนโอน
💡 เคล็ดลับ: การโอนพัสดุทุกครั้งต้องได้รับอนุมัติจากหัวหน้างานก่อน — บันทึกชื่อผู้อนุมัติในช่อง Memo เพื่อการตรวจสอบย้อนหลัง
05
จ่ายงาน
กำหนดและมอบหมายช่างผู้รับผิดชอบงาน PM แต่ละใบงาน พร้อม Dispatch ผ่านระบบ Maximo
# การดำเนินการ รายละเอียด / เส้นทางใน Maximo
1 เปิด Tab Labor เปิด WO → Tab Labor — ตรวจ Planned Labor ที่ระบบกำหนดจาก PM Route
2 เพิ่มช่าง คลิก New Row → ค้นหา Craft หรือ Person จาก Labor Lookup
3 ระบุชั่วโมง กรอก Regular Hours ตามที่คาดว่าจะใช้จริง (เป็นชั่วโมงทศนิยม เช่น 2.5)
4 กำหนดวันเวลา กรอก Start Date และ Finish Date ให้ตรงกับแผนงานจริง
5 Approve และ Dispatch Actions › Change Status › APPR → จากนั้น Dispatch เพื่อส่งงานให้ช่าง
6 แจ้งช่าง แจ้งผ่าน Mobile Maximo, Line หรือส่ง Work Order Printout ให้ช่างก่อนลงพื้นที่
💡 เคล็ดลับ: ตรวจสอบ Craft Availability ก่อน Dispatch ทุกครั้ง — ใช้ Assignment Manager ใน Maximo เพื่อดูภาระงานของช่างแต่ละคน
06
ติดตั้ง MEA Number
บันทึกหมายเลข MEA ของอุปกรณ์ที่ติดตั้งใหม่ลงในระบบ Asset Maximo เพื่อความถูกต้องของ Asset Registry
# การดำเนินการ รายละเอียด / เส้นทางใน Maximo
1 เปิด Actuals Assets WO → Tab Actuals → Sub-tab Assets (ดูอุปกรณ์ที่ใช้จริงในงาน)
2 ค้นหาหรือสร้าง Asset ค้นหา Asset เดิมจาก Asset # — ถ้าเป็นของใหม่ให้ไปที่ Assets › New Asset
3 กรอก MEA Serial Number กรอกหมายเลข MEA ในช่อง Serial # ให้ตรงกับป้ายบนอุปกรณ์ ⚠ ห้ามซ้ำกัน
4 เชื่อม Location ระบุ Location ให้ตรงกับสถานีที่ติดตั้ง (Station ID จาก Step 02)
5 บันทึก Installation Date กรอก Install Date เป็นวันที่ติดตั้งจริงในสนาม ไม่ใช่วันที่บันทึก
6 แนบรูปถ่าย Tab Attachments → อัปโหลดรูปถ่ายป้าย MEA Number ที่ชัดเจนเป็นหลักฐาน
💡 เคล็ดลับ: MEA Number ต้องไม่ซ้ำในระบบ — ค้นหาด้วย Serial # ก่อนบันทึกทุกครั้ง ถ้าซ้ำให้ประสานงาน Asset Team ทันที
07
รื้อถอน
บันทึกการถอดอุปกรณ์เก่าออกจากระบบ จัดการ Asset Status และส่งต่อกระบวนการกำจัดทรัพย์สิน
# การดำเนินการ รายละเอียด / เส้นทางใน Maximo
1 เปิด WO Tab Assets เปิด WO → Tab Assets → ค้นหา Asset ที่จะรื้อถอนด้วย Asset # หรือชื่อ
2 เปลี่ยน Asset Status Actions › Change Status › Decommissioned ⚠ ไม่สามารถยกเลิกได้
3 บันทึก Removal Date กรอก Removal Date ให้ตรงกับวันรื้อถอนจริง พร้อมระบุสาเหตุในช่อง Remarks
4 โอนไป Disposal เปลี่ยน Location ของ Asset → DISPOSAL หรือ Scrap Location ที่กำหนดไว้
5 แนบหลักฐาน Tab Attachments → แนบรูปถ่ายก่อน-หลังรื้อถอน และใบบันทึกรื้อถอน
6 ปิด Work Order Actions › Change Status › COMP — ปิด WO หลังรื้อถอนเสร็จและบันทึกครบ
💡 เคล็ดลับ: ถ่ายรูปป้าย Serial Number บนอุปกรณ์ก่อนรื้อถอนทุกครั้ง — เป็นหลักฐานสำคัญในกรณีที่ต้องตรวจสอบย้อนหลัง
08
สร้าง WBS (Noti 12)
สร้าง Work Breakdown Structure สำหรับงาน PM ตาม Notification Type 12 เพื่อการวางแผนต้นทุนและทรัพยากร
# การดำเนินการ รายละเอียด / เส้นทางใน Maximo
1 เปิดโมดูล Notification Work Orders › Service Requests หรือ Notifications → คลิก New
2 สร้าง Notification Type 12 ระบุ Class = PM และ Type = 12 ในช่อง Classification ให้ถูกต้อง
3 กรอก Description กรอก Description (สั้น) และ Long Description (รายละเอียดเต็ม) ให้ชัดเจน
4 เชื่อม WO หลัก ระบุ Related WO → ผูก Notification กับ Work Order PM หลักของเขต
